# 17歩モード（試作用プロジェクト）

対象: JanshinSteamLocalized 試作用。他の製品版・Demo版・iOS版への反映はしていません。

## 開始方法
メニュー → 対局 → Tier選択画面の「17歩モード」 → キャラクター選択。
初回説明は毎回のモード開始時に表示し、対局中も「遊び方」から確認できます。
専用シーンは実行時に生成するため、Build Settingsへの新規シーン登録は不要です。

## 確定した仕様
- 共通の136枚から各34枚。13枚を構築し、残り21枚から交互に捨てます。敵が先手です。
- テンパイできなくても開始可能。ロン牌が出ると「ロン／スキップ」を表示します。見逃し、または自分の待ちを捨てると、その局はフリテンです。
- 両者17回の捨て牌で流局（両者0点）。1敵3局、合計点が同点ならプレイヤー敗北。
- アマテラス → アヌビス → ポセイドン → ゼウス。敵のスキル・会話はありません。
- 敵は自分の34枚から作れるテンパイ形を列挙し、得点順で3位・2位・1位・1位を採用します。同点の別形も別候補として数えます。
- 敵の捨て牌は現物優先、次に自分から2枚以上見える字牌、それ以外はランダム。相手の手牌を参照しません。
- 2敵目は1枚、3・4敵目は2枚の指定牌があります。選択は任意。未使用または変換して元の牌ではなくなった指定牌は1枚につき1翻減点（役のある和了は最低1翻）。
- 敵は東家・親、プレイヤーは南家・子。3局とも東場。親子・自風・場風を役と点数へ反映し、敵に点数を支払う方式ではなく和了点の累計を比較します。リーチとドラ以外の役があるテンパイで自身の初打時にリーチ（1翻）を宣言し、以降の手牌変換を禁止します。ツモ・カン・副露はありません。
- 染色師と書家は1局2回。資産家は各敵の開始時に3択から2枚を選択します。
- お札は最大3枚。4枚目以降は入れ替えを選択。成立しない門前清自摸和・三槓子・四槓子は除き、29役（立直・一発・河底撈魚を含む）を用意しています。
- 難しい役ほど低レア度で出やすく設定。倍率は1.2 / 1.4 / 1.6 / 1.8 / 2.0。複数発動時は掛け合わせ、100点単位で切り上げます。
- 各敵の勝利で消費アイテム1個を即保存。価格300 / 500 / 700に応じて各アイテムの抽選重み6 / 3 / 1。ゼウスは宝石2個も付与します。
- 敗北・途中終了でも獲得済みの報酬は残ります。途中の対局の再開保存はありません。
- メニューの「消費アイテム」で1個を装備。次の新規通常ランに1回だけ持ち込み、その時点で倉庫から消費します。通常ランの途中再開では再付与しません。

## 主な調整箇所
- SeventeenStepsController.cs: スキル使用回数（SkillUsesPerRound）、チュートリアル、盤面と各ダイアログ。
- SeventeenStepsMode.cs: 敵順、報酬抽選、所持品保存、お札の対象役・倍率・出現重み。
- SeventeenStepsRules.cs: 牌山、テンパイ探索、ロン判定、敵の安全牌選択。
- SeventeenStepsInventory.cs: メニュー入口、所持・装備画面。
- 通常のYakuEvaluatorとScoring、敵イラスト、牌、背景、BGM、カットイン、SEを共用しています。

## 2026-09-21 演出・ドラ更新
- 136枚の同じ山から、配牌68枚とは重ならないドラ表示牌・裏ドラ表示牌を1枚ずつ確保。
- 表ドラは常時、裏ドラはリーチ和了時のみ加算・公開。ドラのみでは役になりません。役満には追加翻を載せません。
- 敵の候補点にはリーチと表ドラを反映し、裏ドラは手作りに利用しません。
- 開局→4枚ずつの配牌（最後は2枚）→13枚確定→敵から交互の捨て牌（各自の初打時に条件付きリーチ）→ロン選択→ロンカットイン→段階的な点数表示→勝敗カットイン、の順序です。
- 通常モードの牌裏、お札画像、レアリティ色とレジェンダリーのオーラ、BGM、配牌・選択・捨て牌・リーチ・ロン・得点段階・勝敗SEを再利用。
- 得点パネルには役・ドラ・裏ドラ・お札補正のみを表示し、HP/MP/Gold/パッシブスキル欄は設けていません。
- 演出の間隔と配置は SeventeenStepsPresentation.cs で調整できます。配牌グループ間隔0.5秒、敵の捨て牌前0.9秒、ロン・勝敗カットイン2.5秒。

演出更新の検証: Unityでロン選択待機・見逃し後の進行・フリテン・リーチ後の手牌固定・ドラ加算を確認。追加の表示検証4項目PASS。表示牌を含む共通山とドラ計算の独立検証150,236項目PASS。

## リーチ・画面の再調整
- 13枚の確定だけではリーチになりません。各自の最初の捨て牌で、リーチ・ドラ以外の役を持つ待ちがある場合に宣言します。
- 敵の初打をプレイヤーがロンした場合、プレイヤーのリーチ・裏ドラは加算しません。
- カットインは入力を遮る透明レイヤー上に画像と文字だけを表示。ポップアップの枠はありません。
- キャラクター選択に通常モードの3人の肖像を使用。盤面の手牌・河・捨て牌候補は背景を分離。
- 消費アイテム画面は所持品の画像・個数・効果と、装備中の1枠を表示。報酬画面も効果を併記。

今回の検証: 牌・役・ドラ判定150,239件PASS。Unityで初打時のリーチ、初打前ロン、枠なしカットイン、消費アイテム装備、メニュー入口を含む10項目PASS。画面キャプチャは Logs/SeventeenStepsQA/15-BoardStyle.png～18-CharacterPortraits.png。配布用ビルドは未作成。

## 満貫条件・常設UI
- リーチ候補はリーチ・表ドラを含み裏ドラ・お札倍率を除いて満貫以上となる待ちを持つこと。実際のロンはその牌で満貫以上が必要。指定牌減点は判定前に反映。
- 満貫未満の待ち牌が出た場合は、以後その局のロンを禁止（敵も同様）。裏ドラは最終得点に加算。
- 初回17歩チュートリアルは SeventeenStepsTutorialDoneV1 に保存し、通常チュートリアルのリセット操作で共に消去。
- 名前・得点は各肖像の上。通常モードのOfudaPanel・SeatWindを流用し、お札3枠を常時表示。
- スキル対象は赤色、手牌・デッキは牌種順に並べ直し。通常手牌と同じ8ポイント間隔。
- メニューの7ボタンを同じサイズの2段配置へ変更。

検証: 満貫高め/安め・裏ドラ除外・指定牌減点を含む独立判定150,250件PASS。Unityで安め出現後に高めでもロンできないこと、メニュー導線、常設お札表示など16項目PASS。
