# 消費アイテム（JanshinSteamLocalized）

対象：`D:/Unity/JanshinSteamLocalized`。2026年9月16日に製品版のアイテム機能・強化画面の共通デザインを移植しました。

## 入手・使用

- 強化画面の「アイテム購入」から、Goldで購入します。
- 強化画面に入るたびに、異なる3種類をランダムに提示します。同じ画面でパネルを閉じて開き直しても再抽選されません。
- 各オファーは1個まで購入可能。価格は300／500／700 Goldです。
- 所持枠は4個。同じ種類を複数持つことも可能です。
- 対局中、左下の「アイテム」から使用します。自分のツモ場4枚が配られ終わった段階で、1ターン1個まで使用できます。ターンは進みません。
- 牌を変更するアイテムは、所持品パネル内で対象と変更先を選んで「使用する」で確定します。確定前に戻っても消費されません。
- 必要な対象がない場合、回復が不要な場合、同じ持続効果が残っている場合は消費されません。
- 未使用品は敵を倒しても持ち越します。敗北・新規ラン開始で全消失します。
- 「この対局中」の効果は同じ敵と戦う間だけ有効。局が進んでも残りますが、敵撃破時に解除されます。
- 中断データには、未使用品・持続効果・そのターンの使用済み状態を保存します。

## Unity上の確認場所

- 実行中の強化画面：`Button_Consumables` → `ConsumableWindow`
- 実行中の対局画面：`Button_ConsumableInventory` → `ConsumableWindow`
- 画像：`Assets/Resources/Consumables/item_01.png` ～ `item_20.png`
- 価格・名称・説明：`Assets/Scripts/RunConsumables.cs`
- 強化画面：`Assets/Scripts/UpgradeSceneMenu_Consumables.cs`
- 使用画面・効果：`Assets/Scripts/GameManager_Consumables.cs`
- 共通パネル：`Assets/Scripts/ConsumableWindow.cs`

各画面は既存Sceneから実行時に組み立てます。既存のボタン画像・フォント・装飾枠を利用しています。

## 購入画面の表示

既存の強化画面に合わせて背景、上部タイトル、左右の「戻る」「次の敵へ」を表示します。購入画面の文字は白・黒縁取り、価格と所持金はお金の袋アイコンと数値で表示します。「次の敵へ」は既存の強化完了処理を呼び出します。

## 検証

Unityメニュー `Tools → Janshin → Validate Consumables` で、購入制限・効果・画像・画面内の文字収まりを確認できます。
結果とプレビューは `Logs/ConsumablesQA` に出力します。検証時のアイテム所持状態・Gold・乱数状態は元に戻します。Sceneは保存しません。

Steamへのアップロードや配信は行っていません。

## 強化画面の共通デザイン

お札購入・ステータス強化・デッキ構築・役強化は `UpgradeManager_Presentation.cs` の共通レイアウトを使用します。上部タイトル、左右の移動ボタン、所持金、白文字と黒縁取り、カード枠を統一しています。ステータスは効果・累計・価格を分離し、お札はレア度に応じたグラデーションを維持します。既存のボタンと参照を再配置するため、UnityのInspectorの価格設定や購入処理は引き続き使用されます。
